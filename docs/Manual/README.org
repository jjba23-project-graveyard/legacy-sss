** Terminology

When keybindings (shortcurts) are defined, the following legend applies (a la Emacs):

| term | meaning                   |
|------+---------------------------|
| ~s~    | Super / Windows / CMD key |
| ~S~    | Shift key                 |
| ~M~    | Meta / Alt / Option key   |
| ~C~    | Control key               |
