#+title: Mail management with GNUS

I have recently taken on the mission of fixing and organizing my insanely cluttered and disorganized mail inboxes in several accounts.

In contrast to my computer, and software that I write, which are organized, structured and neat, my e-mail looks more like Azathoth's wrath was unleashed upon it.

Check the extensive GNUS manual for more information: [[https://www.gnu.org/software/emacs/manual/html_node/gnus/Don_0027t-Panic.html][here]].

** Preparing

For starters, if you plan to use Gmail with GNUS you should create an "application password" which will allow you to connect without OAuth. Note that this is a different password than the usual one, and is buried inside your Google account settings.

Then add your info in ~~/.authinfo~
#+begin_src
machine imap.gmail.com login you@gmail.com port imaps password mypassword
machine smtp.gmail.com login you@gmail.com password mypassword port 587
#+end_src

Then configure GNUS to use Gmail (tweak ~~/.gnus.el~):
#+begin_src elisp
(setq user-mail-address "you@gmail.com")
(setq user-full-name "Your Name")

(setq gnus-select-method
      '(nnimap "gmail"
	       (nnimap-address "imap.gmail.com")  ; it could also be imap.googlemail.com if that's your server.
	       (nnimap-server-port "imaps")
	       (nnimap-stream ssl)))

(setq smtpmail-smtp-server "smtp.gmail.com"
      smtpmail-smtp-service 587
      gnus-ignored-newsgroups "^to\\.\\|^[0-9. ]+\\( \\|$\\)\\|^[\"]\"[#'()]")

#+end_src


Then ~M-x gnus~ should work. You might need ~libxml2~ installed to read HTML mail.
